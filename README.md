# ⏱️ TimeMaster

A modern stopwatch application built with HTML, CSS, and JavaScript. It offers accurate time tracking, lap recording, and a clean, responsive interface for a smooth user experience.

## 🚀 Live Demo
https://time-master-gamma.vercel.app/

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## ✨ Features
- ⏱️ Accurate stopwatch timing
- ▶️ Start, Pause & Reset controls
- 📝 Lap time recording
- ⚡ Smooth animations and interactions
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
